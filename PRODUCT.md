# AccuKnox CNAPP Dashboard (assignment)

## Product

AccuKnox builds a **Zero Trust CNAPP** (Cloud-Native Application Protection Platform) that secures **code to cloud / build to runtime**. Core modules reflected in this dashboard:

- **CSPM**: Cloud Security Posture Management (accounts, risk assessment)
- **CWPP**: Cloud Workload Protection (namespace / workload alerts)
- **Registry / Image**: container image risk and security issues
- **Ticket**: operational follow-ups (starter category in the assignment UI)

Audience: security engineers and cloud operators reviewing posture and risk at a glance.

## This surface

Operate-mode **CNAPP Dashboard V2**: JSON-driven categories and widgets with local add/remove/search. Assignment deliverable for Front-End Trainee. Matches the provided mockup, using AccuKnox brand tokens (Space Grotesk, primary blue `#0046FF`, navy `#11206D`).
